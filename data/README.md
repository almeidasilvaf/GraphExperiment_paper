# Data

- `xiphophorus_networks_calibrated.tre`: time-calibrated phylogenetic networks
  (0, 1, and 3 reticulations) for 23 *Xiphophorus* species, inferred with SNaQ
  by Bastide et al. (2018, Syst Biol, https://doi.org/10.1093/sysbio/syy033).
- `xiphophorus_morphology_Cui_etal_2013.csv`: sword index and female preference
  for a sword in *Xiphophorus* species, from Cui et al. (2013, Evolution,
  https://doi.org/10.1111/evo.12099).

Both files were obtained from the `examples/` directory of the
PhyloTraits.jl package (https://github.com/JuliaPhylo/PhyloTraits.jl, MIT license),
and are also available on Dryad (https://doi.org/10.5061/dryad.nt2g6).
